# minpakuOS StockFlow V3 — 名護倉庫の棚卸数を使うデモ

- 2026/11/18の名護倉庫棚卸データ（12商品）は専用URLフラグメントからブラウザに取り込みます。
- 実棚卸数量は公開GitHubコードには含みません。URLフラグメントは通常HTTP送信されず、読み込み後はアドレス欄から消去します。
- 専用URLを他人へ共有すると棚卸数量も共有されます。取扱いに注意してください。
- 単価は全て説明用の仮値です。実際の仕入価格・請求価格ではありません。
- 初期倉庫数は棚卸数と一致。デモ中の出庫・納品で現在庫が動いても「初期棚卸_名護倉庫」に元の数量が残ります。
- 操作例の再生でスタッフA・Bの車載在庫、施設納品、未請求を体験できます。
- 管理台帳に「初期棚卸_名護倉庫」「数量突合」があり、CSVを取得できます。
- 保存は操作端末内のブラウザのみ。実際のminpakuOS・Google Sheets・LINE・経理には一切接続していません。
