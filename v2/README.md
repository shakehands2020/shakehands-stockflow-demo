# minpakuOS StockFlow V2 — 公開操作デモ

このフォルダは、仕入・倉庫在庫・スタッフ（車載）在庫・施設納品・請求照合を、スマートフォンで試すための静的デモです。

## 試せる機能
- 現場操作：スタッフA〜Eの切替、倉庫から出庫、施設へ納品、担当者間の引渡し申請と受領、倉庫返却。
- 発注・倉庫：発注登録、実入庫数と実仕入単価の登録、倉庫残数の確認、返却受領。
- 経理：未請求明細・請求確定、発注と仕入の数量・単価差異、保管長期化、引渡し未確認、請求単価ルールの変更。
- 管理台帳：8種類のシート形式の台帳を表示し、CSV出力。
- 数量不足拒否・引渡予約・請求の二重確定防止・単価履歴を再現。

## 開発・運用上の注意
- **全データは架空のサンプルです。** 本番在庫・仕入価格・利用者情報は含みません。
- localStorageによるブラウザ内保存のみ。実際のLINEログイン、Google Sheets、Notion、minpakuOSのAPIとは接続していません。
- ブラウザを変えてもデータは同期されません。
- 請求確定はデモ状態の更新であり、会計売上の登録、請求書の実発行やメール送信は行いません。
- 公開Pages用ファイルです。実データ・認証情報を追加しないでください。
